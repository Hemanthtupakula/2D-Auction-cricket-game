# Auction XI Friend Player Assets

V4.2 loads production friend-likeness assets from this folder.

For each in-game identity, provide:

- `<id>.glb` — rigged cricket player model with a humanoid skeleton and animation clips.
- `<id>_face_uv.png` — UV-authored face texture for the head/face material.

Required IDs:

- `ajay_07`
- `akshay_18`
- `gokul_11`
- `hemanth_naidu_27`
- `hkt_17`

The reference photographs supplied for development are kept outside `public/` and are not automatically shipped to players. They are reference material for producing the licensed/consented 3D likeness assets.

Recommended GLB animation clip names are documented in `docs/FRIEND_FACE_ASSET_SPEC.md`.
