# V3 Scope — Dream Gameplay Presentation Rebuild

V3 is the first major gameplay-presentation rebuild, not the final art-asset milestone.

### Implemented in this package
- Complete presentation timeline for one ball.
- Role-specific player actor director.
- Delivery-specific release states.
- Batter intent/timing-driven presentation states.
- Ball trajectory presentation with bounce and arc.
- Outcome-aware field reaction.
- Broadcast camera choreography.
- Stadium/floodlight/crowd world.
- Boundary/wicket FX.
- Broadcast overlay.
- Reset/cancel boundary for reconnect and next-ball transitions.

### Deliberately not faked
- Photorealistic human models.
- Licensed player likenesses.
- Motion-capture animation clips.
- Official team/player assets.
- Sound recordings.

Those require real art/audio assets and should be added as a separate asset milestone rather than hiding them behind primitive geometry.
