# UI Layout — Laptop First

The match is full-browser, not a literal 50/50 split.

## Top bar
Teams | Score | Overs | Target/Need | CRR/Required RR | Pause

## Main arena (about 70–75% visual attention)
2D pitch, bowler, batter, ball trajectory, contact feedback, boundary/wicket effects.

## Compact live information
Left: current batters — runs, balls, 4s, 6s, SR.
Center: this over — dot/1/2/3/4/6/W.
Right: current bowler — O/R/W/Econ.

## Bottom navigation/drawers
[SCORECARD] [COMMENTARY] [STATS] [SQUADS] [MATCH INFO]

Only the latest 2–3 commentary lines are visible during live play. Full ball-by-ball opens as a drawer.

## Pause overlay
MATCH PAUSED
Paused by <owner>
Current score and over remain visible.
[RESUME MATCH]
[EXIT / FORFEIT]

Exit must be visually separated from Resume to reduce accidental forfeits.

## Innings break
Large score/target, top batter, best bowler, [VIEW SCORECARD], [READY].

## Full time
Winner/result, final scores, Player of the Match, [FULL SCORECARD], [BALL-BY-BALL], [PLAYER STATS], [RETURN].

## Playing XI
Squad 25 -> select 11.
Show only auction BAT/BOWL values as source ratings.
Roles are roster metadata; do not invent permanent auction ratings.
