# V4.3 Actual Friend Player Assets

This package adds five real GLB player assets generated from the supplied reference photographs. The in-game identities are AJAY #07, AKSHAY #18, GOKUL #11, HEMANTH NAIDU #27 and HKT #17.

The GLBs are optimized starter character assets with a 3D body/head, cricket equipment, kit materials and a forward face-likeness surface using the supplied reference crop. They are not photogrammetry scans and do not contain authored skeletal animation clips. The existing V4.1/V4.2 runtime therefore remains responsible for presentation-state motion and can fall back to procedural animation.

For final AAA-level animation, these GLBs should later be replaced by professionally rigged humanoid GLBs with animation clips while preserving the exact filenames and manifest contract.
