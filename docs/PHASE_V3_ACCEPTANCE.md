# V3 Acceptance

1. The stage remains playable without the presentation subsystem.
2. Authoritative score/result remains untouched.
3. A delivery produces a complete visual sequence: pre-delivery → run-up → release → flight → batter response → field response → result → reset.
4. Camera changes are presentation-only.
5. Delivery kinds visibly differ in release/flight presentation.
6. Batter intent visibly changes the response animation.
7. Timing bands alter presentation emphasis only.
8. FOUR/SIX/WICKET produce stronger presentation than a dot/single.
9. Fielders react based on the authoritative outcome/trajectory metadata.
10. Presentation can be cancelled/reset safely on reconnect or match-state replacement.
11. No CPU cricket decisions are introduced.
12. No backend, persistence, auction, franchise, or Unity code is required by the subsystem.
