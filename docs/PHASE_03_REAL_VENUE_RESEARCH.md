# Auction XI — Phase 3 Real Venue Reference Set

Ten Indian cricket venues are used as the initial Auction XI home-stadium reference identities. Boundary values are reference geometry for the foundation, not an assertion that a boundary rope is permanently fixed at one number for every match.

| Auction XI | Reference venue | City | Straight reference (m) | Square reference (m) |
|---|---|---|---:|---:|
| MI | Wankhede Stadium | Mumbai | 65 | 71 |
| CSK | MA Chidambaram Stadium | Chennai | 65 | 71 |
| RCB | M. Chinnaswamy Stadium | Bengaluru | 65 | 67 |
| KKR | Eden Gardens | Kolkata | 71 | 66 |
| SRH | Rajiv Gandhi International Cricket Stadium | Hyderabad | 71 | 68 |
| RR | Sawai Mansingh Stadium | Jaipur | 68 | 68 |
| DC | Arun Jaitley Stadium | Delhi | 57 | 64 |
| PBKS | Maharaja Yadavindra Singh International Cricket Stadium | New Chandigarh / Mullanpur | 74 | 65.5 |
| GT | Narendra Modi Stadium | Ahmedabad | 66 | 68.5 |
| LSG | BRSABV Ekana Cricket Stadium | Lucknow | 75 | 76 |

The pitch contract is fixed at 20.12 m x 3.05 m. Later ball/fielding simulation must use the active stadium configuration rather than assuming identical boundaries across all venues.

Visual stadium assets remain original, procedurally generated, user-owned, or properly licensed; this package does not copy third-party 3D assets.
