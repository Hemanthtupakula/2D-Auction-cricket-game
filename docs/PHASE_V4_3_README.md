# Auction XI Phase V4.3 — Actual Friend Player Assets

Drop-in asset package following V4.2. It includes five actual GLB player assets and face textures derived from the supplied reference photographs.

## Game identities
- AJAY #07
- AKSHAY #18
- GOKUL #11
- HEMANTH NAIDU #27
- HKT #17

## Install
Copy the entire `frontend/public/assets/players/friends/` directory into the project's matching directory. Replace the V4 runtime directory only if your V4.2 files are older than this package.

## Important
These are production-ready integration assets, not photogrammetry or motion-captured AAA characters. They deliberately avoid claiming that a photograph was converted into a fully rigged human scan.
